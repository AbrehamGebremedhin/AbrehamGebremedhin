### About

I build end-to-end products where AI does real work — not just a chat box bolted onto a CRUD app. Most of my time goes to designing LLM pipelines that have to be correct (validation, repair, fallbacks) and the full-stack apps that put them in front of users.

- 🔭 Building **SmartStudy** — an Ethiopian-curriculum study app with an LLM pipeline that generates and validates exam questions
- 🧠 Interested in reliable LLM systems: structured output, multi-model validation, job queues, prompt caching
- 🛠️ Comfortable across the stack — React/Vite frontends to Python backends with Postgres
